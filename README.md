# สนามคำศัพท์ — Vocab Arena

เกมฝึกคำศัพท์ภาษาอังกฤษสำหรับคนไทย เล่นแข่งกับเพื่อนได้

## ไฟล์อะไรคืออะไร

| ไฟล์ | ต้องแก้ไหม | คืออะไร |
|---|---|---|
| `config.js` | **ใช่** | ใส่คีย์ Supabase และปรับกติกาเกม — ไฟล์เดียวที่ต้องแตะ |
| `index.html` | ไม่ | โครงหน้าเว็บ |
| `style.css` | ไม่ | สีและหน้าตา |
| `app.js` | ไม่ | ตรรกะเกมทั้งหมด |
| `data/*.json` | ไม่ (สร้างอัตโนมัติ) | คลังคำศัพท์แต่ละระดับ |
| `SETUP.md` | — | คู่มือติดตั้งทีละขั้น อ่านอันนี้ก่อน |
| `tools/supabase.sql` | — | สคริปต์สร้างตารางคะแนน เอาไปวางใน Supabase |
| `tools/build-data.py` | — | แปลง CSV จาก Google Sheet เป็นข้อมูลเกม พร้อมตรวจข้อผิดพลาด |
| `tools/build-single.py` | — | รวมทุกไฟล์เป็นไฟล์เดียว สำหรับส่งให้คนอื่น |

## เริ่มยังไง

อ่าน **`SETUP.md`**

## ทดสอบในเครื่อง

```bash
python -m http.server 8000
```

แล้วเปิด http://localhost:8000
(เปิดไฟล์ `index.html` ตรงๆ ไม่ได้ เพราะเบราว์เซอร์ห้ามโหลดไฟล์ข้อมูลแบบ `file://`
ถ้าอยากได้ไฟล์เดียวที่เปิดตรงๆ ได้ ให้รัน `python tools/build-single.py`)
